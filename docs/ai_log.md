### Задача

Выступить нейросеть аналитиком (пункт №1 задачи по работе с нейросетями).


### Модель 

DeepSeek


### Промпт

```
На текущий момент в данной области отсутствует прямая связь между пользователями и технической поддержкой. Со стороны технической поддержки это затрудняет обнаружение, устранение, систематизацию и предотвращение проблем. Со стороны пользователей это создаёт неопределённость ("уже известно о проблеме?", "о каких проблемах я сообщал ранее, в каком они статусе?").

Необходима система, которая со стороны позволит пользователям удобным способом подавать заявки, а со стороны поддержки быстро реагировать на них.

Будут использоваться следующие роли пользователей:
1. Клиент - создание и изменение содержимого своей заявки, просмотр истории собственных созданных заявок
2. Оператор - просмотр истории созданных клиентами заявок, поиск по каталогу заявок, изменение статуса заявок, назначение заявке категорий
3. Модератор - всё перечисленное у оператора, создание и изменение пользователей, журнал действий по всей системе
4. Администратор - всё перечисленное у модератора, создание и изменение категорий, создание и изменение статусов заявок

Клиент создаёт заявку, за которой закрепляется доступный оператор. Оператор при необходимости выясняет подробности через комментарии к заявке. Клиент отвечает через те же комментарии. После выяснения всех подробностей оператор обрабатывает заявку через собственные каналы вне системы.

У операторов есть доступ на просмотр всех заявок в системе.

Модератор может создавать новые учётные записи для клиентов и операторов.

Выступи аналитиком: выдели роли пользователей, функциональные и нефункциональные требования, сущности предметной области и возможные критерии приёмки.
```

### Почему такой промпт

Структурированный промпт для проверки технического задания.


### Почему такая модель

Модель общего назначения. Результаты запросов подробнее, чем у аналогичной Gemini.


### Результат ИИ

См. документ __ЛР01-02-Структурированный запрос.pdf__.


### Проверка 

Проверил пункты в соответствии с исходным техническим заданием. Нет "из ниоткуда" взявшихся пунктов, остальные соответствуют исходному тексту.


### Собственная доработка

Пункт "Локализация" в разделе "3. Нефункциональные требования" не был уточнён и содержит только "Русский язык интерфейса".


### Вывод

Нейросеть хорошо проверила техническое задания и помимо выделила неоднозначности — как лично мне очевидные сразу (например, тип назначения оператора на новую заявку, нехватку подробностей в постановке задачи), так и неочевидные, которые вынесла в отдельный раздел "6. Открытые вопросы (для уточнения с заказчиком)".
