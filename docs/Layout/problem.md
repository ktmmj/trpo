Ввиду полной моей некомпетентности в создании графических пользовательских интерфейсов, макет был сгенерирован с помощью нейросети Figma по следующим промптам:

```
Сгенерируй ServiceDesk сайт
```

```
Сгенерируй к этому сайту экран входа в систему, экран создания заявки, экран редактирования заявки и карточку заявки с полной информацией
```

```
Сгенерируй всплывающее окно с предупреждением при изменении, удалении и отправке, запрашивающее подтверждение действия
```

После запроса к DeepSeek (см. _UX.pdf_) был отправлен следующий промпт:

```
Нужны следующие исправления:

- Макет ошибок и их положение на страницах
- Выделение активного поля
- Заглушки для незаполненных полей
- Подсказки в форме «Не указывайте пароли, токены…», «Заявитель получит уведомление…», «Заполнено - автоматически по категории»
- Сортировка по колонкам в результатах поиска
```

Финальные результаты см. в _Layout.pdf_.
